# Approved 2.5D Ballroom

The canonical ballroom is generated by `build_ballroom_25d.py` and follows
`reference/approved-ballroom-build-sheet.png`.

## Locked visual rules

- no windows
- no side door
- no wall sconces / lights inside framed panels
- one centered arched mahogany double door
- warm cream plaster + lighter cream trim matching the exterior house
- dark teal wall-to-wall carpet
- very small muted-gold diamond field and simple double border
- one centered ring chandelier
- recessed ceiling glow plus invisible soft architectural light
- no piano or filler furniture in this base scene

## Render

```bash
HECATE_BALLROOM_QUALITY=PREVIEW npm run ballroom:render
HECATE_BALLROOM_QUALITY=WEB npm run ballroom:render
HECATE_BALLROOM_QUALITY=FINAL npm run ballroom:render
```

The script creates `ballroom-25d.blend` and `ballroom-25d.png`. The website
pipeline projects `WORLD_HOTSPOT__ballroom-exit` through
`WORLD_CAMERA__ballroom` and publishes the result automatically.
