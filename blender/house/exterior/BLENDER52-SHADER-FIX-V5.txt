HECATE946 PROFESSIONAL EXTERIOR — BLENDER 5.2 SHADER FIX V5

Cause
-----
ShaderNodeTexMusgrave is unavailable in Blender 5.2.0 LTS, so attempting to
create that shader node raises:

    RuntimeError: Node type ShaderNodeTexMusgrave undefined

Fix
---
The lawn material now uses two supported ShaderNodeTexNoise nodes:
- broad noise for color variation
- finer noise for subtle bump

Permanent project rule
----------------------
Do not instantiate Musgrave shader nodes in Blender 5.2 builders.
Use supported Noise/Voronoi/Wave nodes instead.

Test:
HECATE_EXTERIOR_QUALITY=PREVIEW \
HECATE_EXTERIOR_SEASONS=spring \
blender --background --python blender/house/exterior/build_exterior_25d.py
