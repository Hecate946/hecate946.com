HECATE946 EXTERIOR — BLENDER 5.2 LAWN FIX V6

The lawn no longer uses Geometry Nodes.

Blender's rotation nodes changed across recent versions, and the previous
GeometryNodeAlignEulerToVector identifier is unavailable in Blender 5.2.

The replacement is a deterministic single mesh generated directly by Python:
PREVIEW  8,000 grass tufts
WEB     16,000 grass tufts
FINAL   26,000 grass tufts

Each tuft uses two crossed tapered blades. The path and doorway are excluded,
and the random seed is fixed so every season has identical lawn geometry.

This also suppresses only the noisy Material.use_nodes deprecation warning.
Real runtime errors are not suppressed.
