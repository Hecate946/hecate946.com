ROOM FIX V3
===========

This patch fixes the reason earlier edits could appear to do nothing in Blender:
Blender caches imported Python modules and can also keep an old in-memory copy
of build_rooms.py open in the Text Editor.

Changed files:
- blender/rooms/shared/room_builder.py
- blender/rooms/build_rooms.py
- src/features/immersive/catalog.ts

Important behavior in this version:
- build_rooms.py reloads room_builder.py directly from disk every run.
- AUTO_RENDER_PANORAMA is enabled by default.
- The old panorama is deleted before rendering so a stale file cannot survive.
- The finished panorama and interactive GLB are copied directly into public/scenes.
- The terminal prints: 2026-07-30-v3-solid-surfaces
- Website asset URLs include a cache-busting v3 query.

Recommended run method after unzipping:

  blender --python ~/Desktop/projects/hecate946.com/blender/rooms/build_rooms.py

This opens a new Blender process and executes the file from disk, avoiding stale
Text Editor contents. The console should include:

  Room builder version: 2026-07-30-v3-solid-surfaces

If that exact line does not appear, Blender is not running the patched file.
